All heroes share the same 77-skill pool. Skills unlock by character level (not
class). Each skill has 5 ranks (R1–R5); numbers below show R1 → R5 scaling
unless noted.

HOW DAMAGE / HEALING IS CALCULATED
--------------------------------------------------------------------------------
Physical hit:  floor(STR × str% + weapon attack × 0.25)
Magic hit:     floor(INT × int% + INT × 0.10)

Then enemy resist, buffs/debuffs, and crit (×1.5) are applied.

Example damage in this file uses STR 30 / INT 30, weapon attack ≈ 25, BEFORE
resist and crit. Healing examples use VIT 25.

DoT effects (bleed, burn, poison): % of target max HP per turn.

Stamina is fixed per skill. Cripple adds +1 stamina cost to all skills while active.
Passives cost 0 stamina and cannot be cast from the skill bar.

AOE skills hit the primary target plus adjacent foes in turn order. When 3+
foes are hit, splash targets often take ~85% damage.
